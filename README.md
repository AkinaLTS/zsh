# Introduction

This is a fork by AkinaLTS. Original repository: https://gitee.com/mo2/zsh

```bash
git clone https://github.com/AkinaLTS/zsh
cd zsh
./zsh.sh
```

**Note: To guard against potential supply-chain poisoning, we no longer use mirror repositories and use only the original GitHub repositories. Therefore, a reliable network connection is required.**

We recommend the Powerlevel10k (p10k) theme: it is faster and offers more configuration options.

```bash
zshtheme p10k
# After switching to the theme:
p10k configure
```
